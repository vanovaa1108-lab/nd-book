## Tahap 3: Debugging

| Masalah | Saran AI | Validasi & Modifikasi Mandiri |
|---|---|---|
| Sampul muncul dobel (kotak warna otomatis dari JS + gambar di HTML) dan 2 buku sampulnya tidak muncul/tertukar di GitHub Pages | Menghapus pembuatan elemen `.sampul` otomatis di JS dan menyamakan `src` gambar di `index.html` dengan nama file di folder `img/` | Memeriksa langsung repository `img/` di GitHub serta hasil tampilan di GitHub Pages dan Inspect secara mandiri, lalu menyamakan `src` gambar (`img/kecerdasan-artifisial.png.jpeg` dan `img/detektif-smkn2.png.jpeg`) dan menguji ulang. |
| Gambar sampul terpotong saat memakai `object-fit: cover` dan muncul typo `backround-color` di `css/style.css` | Mengubah `.sampul-gambar` menjadi `object-fit: contain`, mengatur tinggi yang sesuai, dan memperbaiki `background-color` | Mengedit langsung `css/style.css` di GitHub (`object-fit: contain`, tinggi sampul yang disesuaikan, `background-color: white`), lalu mengecek tampilannya di browser sendiri. |
| Sampul *Rahasia Perpustakaan Tua* belum muncul dan memunculkan error `404` saat diakses langsung, serta ukuran sampul ingin dibuat lebih besar dan menyatu (`white`) | Mengecek nama/keberadaan file di folder `img/` saat muncul `404`, menyesuaikan `.sampul-gambar`, dan melakukan hard refresh/cek cache | Mengecek langsung folder `img/` secara mandiri dan menemukan nama filenya tertulis `Perpurtakaan`, menyamakan nama/path file, lalu menguji ulang hingga sampul *Rahasia Perpustakaan Tua* muncul di browser. |
| Tombol kategori (`Semua`, `Novel`, `Pelajaran`, `Komik`, `Teknologi`, `Sejarah`, `Motivasi`) tidak bisa diklik dan jumlah keranjang belum tersinkronkan saat awal dibuka | Memeriksa `js/app.js`, menambahkan *event listener* pada `tombolKategori` dan `kolomCari`, memanggil `updateJumlah()` di awal, serta mengganti `js/app.js` dengan kode lengkap | Mengganti isi `js/app.js` di GitHub dengan kode yang sudah diperbaiki, menjaga pemisahan file proyek, lalu menguji klik semua kategori dan hard refresh (`Ctrl + Shift + R`) di browser. |
| Link Keranjang di halaman utama sempat terlihat polos seperti teks biasa dan tombol WA tidak terlihat di halaman katalog | Menjelaskan bahwa tombol **Beli Produk** (WA) berada di `keranjang.html` serta merancang tombol keranjang berciri khas transparan (ikon + `.badge-keranjang` + tombol kapsul) di `index.html` dan `css/style.css` | Mengecek halaman katalog (`index.html`), memasang tombol keranjang transparan berciri khas dan tombol **Kembali ke Katalog**, lalu menguji navigasi antarhalaman serta tombol **Beli Produk** di `keranjang.html`. |
